# chat-2048 privacy policy

*Last updated: October 21, 2026*

chat-2048 is a private tool that runs a single YouTube channel: a 24/7 live stream of a 2048 game played by its chat, plus short videos made from it. It is used only by the channel's owner. It is not offered to anyone else.

## What it accesses

With the channel owner's permission (Google OAuth), it uses the YouTube Data API and the YouTube Analytics API to:

- create and manage the channel's live broadcasts
- read the live stream's chat, likes and public new subscribers so the game can react to them
- upload Shorts to the channel
- read view counts, watch time and retention for the channel's own videos

## What it stores

It stores the OAuth token on the owner's own server so it can act for the channel. It also keeps the stats listed above for the channel's own videos. Chat messages and viewer display names are used live to run the game and are not sold or shared.

## Sharing

No data from Google APIs is sold, shared with third parties or used for advertising. chat-2048's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. It also follows the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).

## Revoking access

The channel owner can revoke access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
